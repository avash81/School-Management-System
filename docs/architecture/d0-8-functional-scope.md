# D0.8 — Final Functional Scope

## MVP

Identity/session management; school setup; RBAC and scope enforcement; students, guardians, teachers, assignments, academic structure; attendance; examinations; manual marks and result lifecycles; marksheets; notices; core reports; private storage; audit; jobs; backup, monitoring, and test baseline.

## Release 1.1

CSV/XLSX import with human review, bulk documents/exports, richer dashboards, configurable notifications, student and parent read-only portal, and configurable approval policies.

## Advanced / future

AI/OCR provider pipeline, template editor, AI evaluation/optimization, SMS/WhatsApp, feature flags/quotas, multi-school SaaS billing, offline sync, finance/library/transport modules.

## Explicit exclusions

No uncontrolled automatic marks import, public personal-data links, direct browser-to-database writes, or platform-admin routine access to school academic data. A scope change requires traceability, data/security/API/test impact review.
