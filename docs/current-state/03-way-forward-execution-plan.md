## 0. Current Decision and Ordered Plan (2026-10-09)

The project owner selected **complete remediation and freeze architecture first**. No new feature endpoints, entities, schema, or product behavior are authorized before the design gate. Documentation-only remediation and evidence gathering continue. A separate correction of an existing defect would still need to be clearly non-feature work, traced to the governing contract, and explicitly authorized.

### Product objective to carry through the gate

Build a student- and teacher-friendly school platform with **manual marks entry and AI-assisted document entry as equal supported paths**. AI should reduce repetitive transcription by extracting and proposing marks from supported files; a teacher or authorized approver verifies the data before it becomes official. Both modes must share the same academic configuration, tenant/assignment permissions, marks validation and status semantics, official marks/result service, audit trail, and publication rules. AI must remain optional; manual entry must work when AI or upload processing is unavailable. See the [hybrid marks-entry workflow](../architecture/hybrid-marks-entry-workflow.md).

This product objective and the current gap findings are summarized in the [current position and gap analysis](./01-current-position-gap-analysis.md). The direction aligns with the current master spec and `REQ-MRK-001`, `REQ-MRK-002`, and `REQ-AI-001`. It does not itself approve changed scope, support for every file/handwriting type, a particular approval policy, or any competitor-exclusivity claim.

### Cross-Cutting Infrastructure:

```mermaid
flowchart TD
    A[Request enters] --> B[Security Headers + CORS]
    B --> C[Cookie Parser]
    C --> D[RequestId Interceptor\nUUID or x-request-id]
    D --> E[Env validated? No → 503 early]
    E --> F{Public endpoint?}
    F -->|Yes| J[DTO Validation + Zod DTOs\nUnknown: 400 reject]
    F -->|No| G[AuthN Guard\nCookie → hash session\nRevoked/expired: 401]
    G --> H[Set req.user = AuthenticatedUser\nwith id,schoolId,roles[],permissions[],scopes[]]
    H --> I[Permission Guard\nRequirePermissions(...)?\nScope filter (teacher class/section)]
    I --> J
    J --> K[If-Match rowVersion check on update\n409 on stale]
    K --> L[Idempotency-Key check\nIdempotencyService → Redis]
    L --> M[prisma.$transaction\nqueries + business policies]
    M --> N[Append AuditLog JSONB\nwith old/new values,outcome,correlationId]
    N --> O[If async work:\ncreate JobRun row +\nBullMQ Queue.add atomic]
    O --> P[ApiExceptionFilter maps errors]
    P --> Q[Response {data,meta:{correlationId,nextCursor?,rowVersion?}}
            OR {error:{code,message,fields?},meta:{correlationId}}]
```

This pipeline IS the contract. Every deviation = Bug/Backlog.
